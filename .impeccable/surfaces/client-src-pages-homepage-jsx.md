# supperFastShop storefront

Scope: whole client (home, category, product, cart, auth, admin, settings). Mode: Persuade on home, Operate elsewhere inside the same world.
Audience: young streetwear shoppers on phones. Action: add to cart, then pay. Constraints: no photo on every surface; modular code.

## Direction contract

THESIS: The shop is a garment tag. Prices, sizes, categories and the cart are tag objects (price-gun stickers, woven labels, barcodes, die-cut swing tags) rather than photo cards; it refuses the photo-grid store with a hero banner.
OWN-WORLD: Drenched safety-orange field, ink black print, off-white tag stock, one acid-yellow price-gun sticker ink. Tags are die-cut with a punched hole and string; woven labels are black-on-white blocks; sizes are stamped cells, sold-out sizes are ghost cells; barcodes, care-symbol icons and stitch-dash rules are the dividers. Condensed heavy display type, plain grotesk body, tabular numerals for price. No offset block shadows, no gradients.
STORY: A visitor sees a tag with the shop name, a size run and a SHOP NOW sticker, understands it is a fast clothing store, taps a category tag or searches, picks a size and adds to cart, and pays via Stripe. Settings let them change the field colour.
FIRST VIEWPORT: Full-bleed field colour. One oversized die-cut tag hangs from a string at left-centre (about 60% of width on desktop, near full width on mobile) carrying SUPPER FAST SHOP in display type, a stamped XS-XL size run, and an acid-yellow SHOP NOW sticker as the primary action; a search input sits on the string above it; category tags fan along the bottom edge.
